# Security Policy

We are currently providing security updates for the following versions of `aes-gcm-stream-wasm`:

| Version | Supported          |
| ------- | ------------------ |
| 0.x.x   | :white_check_mark: |

## Reporting a Vulnerability

We take all security vulnerabilities seriously. Thank you for taking the time to responsibly disclose any issues you find.

To report a vulnerability, please email us at `security+open-source@transcend.io`. For more information on our security policy, see [https://transcend.io/.well-known/security.txt](https://transcend.io/.well-known/security.txt).
